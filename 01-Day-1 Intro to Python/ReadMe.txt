Object-Oriented Programming (OOP)
OOP is a programming approach where you organize your code into objects. An object contains data (variables) and actions (functions/methods) that work on that data.

Simple Example
Think of a Car.

Data (Properties): Color, Brand, Speed
Actions (Methods): Start(), Stop(), Accelerate()

In OOP, you create a Car object that contains both the data and the methods.

class Car:
    def start(self):
        print("Car started")

car = Car()
car.start()

Functional Programming
Functional programming is a programming approach where you write your program using functions.
def add(a, b):
    return a + b

print(add(5, 3))
