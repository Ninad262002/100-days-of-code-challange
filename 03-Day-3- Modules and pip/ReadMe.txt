Modules and pip in Python!

Modules is a code liberary can be used to borrow code written by somebody else in our program.
Modules Types
1. Built In Modules (modules which comes when you install python)
2. External Modules (These modules are imported from a third party file or can be installed using a package manager like pip )

PIP 
pip is a package manager which is used to install python modules.
ex - pip install pandas
